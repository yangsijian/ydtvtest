# 微信版部署包

这个目录是给微信里打开准备的独立静态站版本。

## 部署根目录

直接上传这个目录即可：

`/Users/macmini/Documents/Playground/wechat-deploy`

## 入口文件

- `index.html`
- `wechat.css`

## 适用场景

- 微信聊天里发链接
- 朋友圈落地页
- 客户手机端快速浏览

## 部署方式

可直接上传到任意静态托管平台，例如：

- 腾讯云静态网站托管
- Cloudflare Pages
- Netlify
- Vercel

不需要构建命令。

## 精简版播放列表

仓库包含一个基于 `ipv6.m3u` 生成的精简版文件：

- `ipv6-lite.m3u`

精简规则：

- 保留常用分类：`苹果盒子`、`央视频道`、`卫视频道`、`4K超清`、`体育频道`、`港澳台`、`少儿动漫`、`新闻纪实`、`电影戏剧`
- 按 `分类 + 频道名` 去重，保留首个源
- 去掉体量更大但噪音更高的 `地方频道`、`国际频道`、`其他频道`、`综艺音乐`
